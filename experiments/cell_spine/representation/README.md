# 求解器选择存储表示

这次直接扩展 Gurobi 的可选表示，不在生成之后手工删节点。没有修改 egglog 引擎。

每个已选 spine 可以使用完整 canonical 存储、借用已有 raw 输入，或仅保存一棵子树并由 marker 保存边界参数。只有通过全部生成路径的存储检查，后两种表示才会加入候选。所有生成、继承、退休和导出规则使用同一份接口。

## 原生运行结果

每项输入为 1,000 份。每个模式只计时一次；规模检查在独立进程完成。native 是当前修改过的 egglog 内核的普通执行，不是 pristine 上游。

| 输入 | 旧生成程序 ms | 求解器新选择 ms | native ms | 展开后 e-node / e-class |
|---|---:|---:|---:|---:|
| long_spine_graft | 15.389 | 4.815 | 7.959 | 18,000 / 18,000 |
| assoc | 7.229 | 7.043 | 6.554 | 15,000 / 7,000 |
| eggcc_if | 99.014 | 96.593 | 45.033 | 16,208 / 14,108 |

三例的展开节点/类数量都与参考值一致。这里是**规模对照，不是完整图等价证明**。编译器对小规模 source 和各入口仍执行原有的原生完整校验。

## 长链发生了什么

- 两端都自动选中借用输入的表示；额外 canonical 节点从 7,000 降到 0。raw 输入仍保留，没有宣称压缩这部分。
- 全部物理表行从 25,000 降到 18,000，候选行访问从 96,000 降到 46,000。
- 推理 15.389 → 4.815 ms；安装、输入及推理合计 143.771 → 134.060 ms。native 总计 128.916 ms，**端到端仍未超过 native**。
- RSS 峰值 37.81 → 35.16 MiB；不能用 canonical 节点减少比例代替 RSS 压缩率。

主要转移自动变为：

```egg
(rule ((Spine-Summary-0 root) (= next (Spine-Extend root extra)))
      ((Spine-Summary-1 next root)
       (subsume (Spine-Summary-0 root)))
      :ruleset Spine-Run)
```

退休规则只保留大、小两个 marker。晚到的小 marker 仍可触发退休。导出阶段按选中的 raw 读取方案恢复输入和闭包。

## 尚未解决的部分

- AC 选择与旧版完全相同，库文件哈希一致；计时差是单次波动。
- If 仍选 canonical。仅减少 150 次候选行访问（1,276,552 → 1,276,402），没有消除长而碎的失败 Join；约 2.4 ms 的差值不足以证明稳定加速。
- 成本还是结构计数，不是运行时间模型。共享模板描述数也不是实例内存；借用以后仍需要导出描述。
- 边界省略目前限于单根、一个直接复合子树、没有 seed union guard 的情况；多根必须保留完整相关性检查。不支持任意逐节点布局枚举。
- 当前只移除可以静态证明冗余的解码，不进行概率近似或按样例猜测。

## Bake 与求解器大小

这里复用已有分析目录，时间包括程序准备、选择及小规模原生校验，不包括 tier-0 历史采集。

| 输入 | Bake 秒 | 最大变量数 | 最大约束数 |
|---|---:|---:|---:|
| long_spine_graft | 2.767 | 202 | 1037 |
| assoc | 0.503 | 74 | 122 |
| eggcc_if | 179.412 | 217 | 590 |

三个模型都在本机受限许可证的 2,000 变量 / 2,000 线性约束范围内。If 的约 179 秒主要仍耗在有限布局组合的定价准备；没有加入候选预算、抽样或贪心回退。这不是任意规模都能满足受限许可证的保证。

## 复现

需要已有的 `joint_pricing` 和 `spine_ablation` 产物（保留原始候选、工作负载和旧库），以及当前 release 原生二进制。

```sh
out/cell-spine-venv/bin/python experiments/cell_spine/representation/run.py \
  --catalog-root out/joint-pricing-verified \
  --ablation-root out/spine-joint-ablation \
  --output out/spine-representation-new
```

`report.json` 保存输入、二进制和编译器源码哈希；输出目录包含生成库、计时/计数输入和日志。

50 项相关测试通过，包含所有已加入的存储模式混合、迟到事实、union、不同 constructor 参数不能由输出相等推出相等、共享尾部、多个来源的相关性，以及借用时必须保留的 root union。
