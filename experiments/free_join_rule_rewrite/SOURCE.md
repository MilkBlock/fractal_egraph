# Runtime source

The local runtime source is the official egglog `v3.0.0` source tarball expanded at
`vendor/egglog-3.0.0-src`.

Download URL:

```text
https://codeload.github.com/egraphs-good/egglog/tar.gz/refs/tags/v3.0.0
```

The vendor directory is intentionally ignored. It contains upstream source and local build
artifacts; the experiment sources and compact results remain separate from that import.
