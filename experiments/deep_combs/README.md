# 扩大 comb 的依赖深度

从同一份 math_microbenchmark 前 5 轮历史中的 582 个依赖根事件，分别
提取深度 1–4 的祖先窗口。学习路径不查询 block owner，也不要求窗口
互斥；一个事件可以参与多个窗口。没有增加优化器运行轮数。

## 图表示与检查

窗口采用 BFS 最短依赖距离截断。节点按首次访问规范编号，一份窗口中
同一 `(scope, match_event)` 只定义一次。所有边引用节点表，保留多源
汇合、共享祖先和 producer alias。同名规则的不同执行不会被合并。

每个展开事件保存局部 normalized binding、局部 producer 角色到窗口
节点的映射、源/目标位置、边界端口和未解释读取数量。规则定义仍保存在
共享字典中。到达深度限制标记 `depth-frontier`；缺少更早记录标记
`no-recorded-incoming`，不声称它一定是原始输入。额外 union 支撑保留
外部标记及证据中的事件 ID，不凭空生成新的 union 因果边。

全部 2328 个窗口都解码核对节点、边和局部 wiring。窗口数据中的 evidence
引用原始 witness 内容，source_nodes 保留局部 ID 到事件 ID 的映射。
这是一种确定的引用编码，不是完整图同构规范形；babble 目前学习的是
这个显式 DAG 编码的语法，尚未实现一般图模式挖掘。

| 依赖深度 | 不同窗口编码 | 含共享祖先的窗口 | 最大事件数 | 最大边数 |
|---|---:|---:|---:|---:|
| 1 | 124 | 0 | 4 | 3 |
| 2 | 348 | 111 | 9 | 9 |
| 3 | 522 | 250 | 11 | 13 |
| 4 | 557 | 318 | 12 | 15 |

每个深度都覆盖同一批 582 个根事件。182 个事件参与多个窗口。

## 固定根事件的学习对照

为了将“增加深度”与“增加样本”分开，学习实验固定 124 个根事件：每个
原始一跳类别选一个已有历史最深的实例，同深度选较早事件。四组使用
相同根事件、相同 99/25 划分。全部 582 窗口另行导出，没有只保留学习子集。
这是有意挑选的同历史重叠窗口，不是独立运行上的泛化测试。

配置沿用 connected-comb 学习：候选必须包含一条具体规则连接，最多
4 个库、3 个参数、beam 16、2 次 library rewrite 迭代，无领域等式。

| 深度 | 学习 AST 原始→库表示 | 留出 AST 原始→库表示 |
|---|---:|---:|
| 1 | 8147 → 8053 | 2030 → 2035 |
| 2 | 17824 → 16832 | 4212 → 4222 |
| 3 | 26565 → 23819 | 6191 → 5943 |
| 4 | 30192 → 26982 | 7116 → 6751 |

定义和调用成本计入；四组全部无损展开通过。深度 4 的 AST 降幅约为
10.6% / 5.1%。但精确子树 DAG codec 仍然更小：深度 4 学习集为
51049 → 51716 字节，留出集为 24383 → 24878 字节。因此深度确实提供
了更多可复用结构，当前 AST 目标选出的库还没有超越这份 DAG 存储基线。
这些数字不代表运行时 RSS，规则字典及其他固定元数据另列。

深度 4 已选抽象中，F23 包含四个事件记录：三个 R23（分部积分）和一个
R1（乘法交换），其中还调用 F887。F887 共享 R23→R23 的 Mul 与 Integral
两条连接。F23 在学习语料中引用 3 次、留出中 0 次；F887 的显式引用为
42/8 次。这比单条边多出了组合层次，但尚不是任意深度的递推证明。
精确定义以 `depth-4.learning.json` 为准，内部库 ID 可随运行变化。

## 深层样本暴露的库顺序问题

初次深度 3 运行被独立展开器拒绝：某个 lifted library 引用了排在它
后面才定义的库。适配器现对纯、封闭的顶层库定义按依赖拓扑排序；原顺序
合法时保持不变。自由变量、遗漏定义和循环依赖仍报错，不把后向引用
偷偷当成可用的 lexical binding。修复后深度 3、4 都通过展开验证，且
增加了依赖顺序与缺失定义的回归测试。

## 复现

```
python3 tools/babble_adapter/scripts/deep_combs.py --learn
python3 -m unittest discover -s tools/babble_adapter/scripts -p test_deep_combs.py
cargo test --release --locked --manifest-path tools/babble_adapter/Cargo.toml
```

不带 `--learn` 只重建图窗口和结构统计。每个学习进程有 180 秒预算；
超时或失败明确写入 summary，不计为成功压缩。较大的 `.windows.json`
和 `.programs.json` 可复现但不提交。未来扩大样本规模可直接使用所有
582 根事件导出的窗口；当前学习比较仍只使用固定的 124 根事件。
