# Cell 的搜索替代收益

本报告完全读取已有 raytrace Pass 3 记录，**没有重新运行推理或计时**。
缓存率回答“读的时候复用了多少”，本指标回答“原来的搜索有多少不再需要送往 GPU，以及 Cell 为此做了什么”。

## 主账：少启动多少，少枚举多少

固定输入、调度及正确结果。设 S 为多 atom 查询的有效起点次数，V 为 GPU 内层活候选行访问次数：

```text
外层替代率 = (S_off - S_on) / S_off
内层替代率 = (V_off - V_on) / V_off
```

当前已有同二进制关/开对照给出：

| 工作 | Cell 关闭 | Cell 开启 | 减少 |
|---|---:|---:|---:|
| 外层起点 | 40,587,639 | 13,278,476 | 27,309,163（67.28%） |
| 内层活候选行访问 | 72,750,548 | 48,033,034 | 24,717,514（33.98%） |

两列不相加，保留每一层的分布。单个 program 的贡献分母使用**整个基线**，而不是它自己那条规则的工作量；否则每条被接管的规则都变成 100%，无法比较价值：

```text
program 外层贡献 = 该 program 关联查询移除的起点 / 整个基线起点
program 内层贡献 = 该 program 关联查询移除的行访问 / 整个基线行访问
```

| 程序 | 外层贡献 | 内层贡献 | CPU 根评估 | CPU 新端口读 | CPU 缓存端口读 |
|---|---:|---:|---:|---:|---:|
| Expr-size / If | 11.06% | 2.23% | 13,607 | 20,035 | 32,701 |
| Expr-size / Get | 2.83% | 1.70% | 994,600 | 977,455 | 0 |
| Expr-size / Switch | 5.53% | 0% | 0 | 0 | 0 |
| 候选结果改善 | 0.62% | 12.74% | 202,081 | 536,749 | 56,030 |

读法：If 以少量局部处理承接了很大一部分外层搜索；候选改善承接的内层枚举最多；Get 有贡献，但仍需很多局部读取；Switch 的价值体现在外层，不能因没有实例/缓存命中而判为无用。Switch 仍回答了 1,798 次请求，不是零成本。

## 成本账：不能把搬到 CPU 的工作算成免费

所有程序的根评估、新端口读、缓存读，以及共享比较证明、通知、存储记录都保存于 `results.json`。不同操作的成本和粒度不同，**不允许做 GPU 行访问减 CPU 索引读，也不以任意权重加出一个“净操作数”**。

这些计数还没有穷尽订阅遍历、guard、分配、同步等成本。三个 Smaller 程序的普通端口读是零，但它们使用的共享比较证明另记 1,185 次饱和处理、211,572 次起点评估、151,307 次代价读取；不能据前面的零宣称它们免费。

这套指标覆盖的是当前 compact GPU 查询计数器的多 atom 起点和内层候选访问。单 atom 查询、设备调度、结果传输、RHS 的收益不能全部从这两列判断，因此零贡献不等于总成本上毫无价值。

## 最终决定：净推理耗时降幅

```text
净收益 = (T_off - T_on) / T_off
```

T 包括运行期 Cell 维护、交接、剩余搜索和原生 effects。setup、Bake、extraction 单列。必须满足正确性门槛，并使用同输入、同调度、同二进制/worker、其它优化开关一致且无插桩的关/开对照。即使搜索减少，净收益仍允许为负。

本报告的工作量对照开了诊断计数器，**当前这张表的净时间收益未测**。不使用这些插桩秒数或旧版 GPU 控制来补造速度结论。可给 `cell-value` 添加 `--timing-before DIR --timing-after DIR`，工具会验证对照并计算净收益。

若要判断“单独保留 C 值不值得”，真正的边际量是：

```text
单 Cell 边际时间收益 = T(完整库去掉 C) - T(完整库)
```

当前没有做逐 Cell 删除实验。因此表里的 program 贡献是全开/全关变化的工作归属，**不是独立因果收益**；共享子结构和维护成本不能重复领功。程序未归属的变化单列为 `unassigned`，不强行分摊。

## 使用

```sh
/opt/homebrew/bin/python3 skills/cell-assisted-egglog-bench/scripts/bench.py cell-value \
  --input out/cell-case-telemetry \
  --before out/join-depth-final-s0r1 --after out/join-depth-final-s1r1
```

`--output NEW.json --csv NEW.csv` 导出账本，不覆盖已有文件。全部 31 个已安装参数化程序见 [CSV](programs.csv)，计数/来源/公式范围见 [JSON](results.json)。这些不是任意 Analyze 库里各个 RipSat e-class 的命中或效益统计。

验证：33 个 skill 测试通过，涵盖零缓存但有收益、空回答价值、负收益保留、共享证明成本、拒绝插桩和混合二进制计时。本次没有改动匹配、Cell 或原生执行引擎。
